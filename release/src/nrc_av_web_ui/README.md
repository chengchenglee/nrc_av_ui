# sylphy

a simple UI to demonstrate a workflow from broker to agent

## Technologies

- [ReactJS v18](https://reactjs.org/) for main UI library
- [Typescript v4.9](https://www.typescriptlang.org/docs/)
- [React Query v4](https://tanstack.com/query/v4/docs/react/overview) and [Axios](https://axios-http.com/) for managing Restful API
- [Ant Design v5](https://ant.design/) for UI components
- [Vite v4](https://vitejs.dev/) for development server/environment

## Start project

install dependencies

`npm install`

start develop server

`npm start`
